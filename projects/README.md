# 子项目目录

每个研究项目使用独立目录：`001-项目短名`、`002-项目短名`、`003-项目短名`……

编号从 `001` 开始，表示收录顺序；项目之间可独立运行和研究。总索引见 [仓库首页](../README.md#项目索引)。

各子项目说明能力、原理、输入输出、应用价值和验证边界。[001 · Infinite Bookshelf](./001-infinite-bookshelf/README.md) 提供写书流程研究、一图总览、摄影与电商样稿，以及可替换模型的本地实验。完整收录列表和网页入口由 [仓库首页索引](../README.md#项目索引) 统一维护。新增项目可使用 [新增项目指南](../CONTRIBUTING.md)，工具会复制 [研究模板](../templates/project/)。

每个子项目至少包含：

- `project.json`：编号、摘要、来源、状态、图片和演示入口。
- `README.md`：研究导读、复现过程、源码分析与结论。
- `assets/`：预览图、截图及相关图片。
- `experiments/`：实验代码和复现说明。
- `web/`：可选 Web 演示和运行说明。

首页索引由各项目的 `project.json` 自动生成，请勿手工调整索引行顺序。已有项目归档时，保留原编号和目录，将状态改为 `archived`。
