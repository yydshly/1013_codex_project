## 目录

1. **先确定主体 再整理画面**：用桌上的杯子说明主体、背景和画面边缘的关系，比较居中与三分位置构图，完成三张只改变构图的练习。
2. **用自然光拍清楚主体**：在窗边观察光线方向与阴影，说明对焦和亮度调整的区别，排查模糊、过亮和色偏，并完成同一主体的对比练习。
3. **完成一次拍摄并复盘**：把构图、光线和清晰度整理成一份短时拍摄任务，通过选择照片、记录问题和针对性重拍，建立可重复的练习方法。

## 第 1 节 先确定主体 再整理画面

### 开始前先说清楚想拍什么

拿一个杯子放在桌上，打开手机相机。先用一句话描述你的拍摄意图，例如“我想拍出杯子的轮廓和窗边安静的感觉”。这句话帮助你决定杯子在画面中占多大，以及哪些背景值得保留。

摄影中的“主体”是你希望观看者首先关注的对象。它可以是杯子、一个人或一片光影。画面里出现很多东西时，先确定哪一个最重要，再安排其他东西的位置。

### 先调整背景 再按快门

拍杯子时，桌上的充电线、纸巾包装和亮色杂物可能抢走注意力。你可以整理桌面，也可以改变站位，让这些东西离开画面。保留背景要有理由：窗户能说明光线来源，桌面能交代杯子所处的环境。

向杯子靠近一点，通常会让它在画面中占得更大。距离太近时，杯口或底部又可能被切掉，也可能超出相机能清楚对焦的范围。因此，移动后检查整个杯子的边缘和清晰度。

同样一个杯子，可以从桌面高度、稍高的位置或斜侧面拍摄。角度会改变你看到的杯口、杯身和背景。先移动手机和身体，观察画面变化，再决定是否需要切换镜头或裁切。

### 比较居中与三分位置

相机中的网格线常把画面分成九格。把主体放在网格线附近，是三分法的一种用法。它可以帮助你安排主体与留白，但不是合格照片必须遵守的规定。

如果杯子和背景具有明显的对称关系，居中也可能更清楚。初学时可以拍两种版本，比较哪一种更符合刚才的拍摄意图。不要为了把杯子移到某个交点，留下大块没有作用的背景。

### 拍摄前检查画面边缘

注意杯口和把手有没有被意外切掉，背景中的线条是否穿过杯子的关键部位，桌沿是否无意中倾斜。画面需要倾斜时可以主动选择；没有这个意图时，先把明显的水平线摆稳。

试着缩小预览，看看第一眼是否仍然能找到杯子。如果最亮的包装袋比杯子更醒目，可以移动包装袋、换角度或重新安排画面。

### 本节练习

保持同一个杯子、同一处光线，拍三张照片。本轮只比较构图，不额外使用滤镜。

| 照片 | 只改变这一项 | 拍完观察 |
| --- | --- | --- |
| A | 杯子居中 | 主体是否明确，左右是否平衡 |
| B | 杯子靠近一条网格线 | 留白是否有意义 |
| C | 改变拍摄高度或左右站位 | 背景是否更清楚，杯子是否完整 |

从三张中选一张，写下一个具体理由，例如“这张背景没有包装袋，把手也完整”。“更高级”太笼统，难以指导下一次拍摄。

## 第 2 节 用自然光拍清楚主体

### 先观察杯子怎样受光

把杯子放在窗边，观察朝向窗户的一面和背向窗户的一面。如果窗户位于杯子的侧面，明暗变化通常更容易表现杯身的形状。缓慢转动杯子或改变手机位置，看看把手的阴影和杯口的亮部怎样变化。

窗边的光不一定柔和。太阳直接照进来时，阴影可能很硬；没有直射阳光、光线较散时，明暗过渡往往更柔和。先观察实际效果，再决定要留下硬阴影，还是移到没有直射光的位置。

如果室内暖色灯也照着杯子，白色杯身的不同位置可能出现不同颜色。入门练习可以先关掉这盏灯，只用窗光，减少比较时的干扰。实际拍摄中也可以主动使用混合光线，只是需要留意局部色偏。

### 分开检查对焦和亮度

对焦决定哪个距离上的细节清楚，亮度调整则影响画面明暗。照片亮起来，并不意味着杯子的字样就对上焦了。

以 iPhone 照片模式为例，可以点按杯子所在区域选择对焦位置，再拖动对焦区域旁的曝光控制调亮或调暗。其他手机的按钮、滑杆和锁定方式可能不同，应按相机界面操作。本练习不要求使用专业模式。

选择杯身上有文字或明确边缘的位置，拍摄后放大查看。杯子较近时，如果怎么点按都不清楚，先把手机稍微移远，再试一次。

### 调亮之后还要看细节

当亮窗户占据很大面积时，手机的自动亮度判断可能让杯子显得较暗。可以改变角度，减少画面中的亮窗，也可以在手机支持的情况下小幅调高亮度。

白杯的亮部如果已经变成没有层次的一片白，继续调亮通常会丢失更多细节。此时可以调暗一点、改变受光位置或避开直射反光，再比较杯口和杯身的纹理是否保留下来。目标是得到符合意图的明暗与细节，不是让整张照片尽可能亮。

### 模糊时先找原因

| 观察到的问题 | 可以先尝试的动作 |
| --- | --- |
| 整个画面都拖影 | 握稳手机，借助桌面等可靠支撑，等拍摄结束再移动 |
| 背景清楚，杯子不清楚 | 重新选择对焦位置；距离太近时稍微移远 |
| 手机很稳，移动的人仍然模糊 | 选择更充足的光线，或等主体停下再拍 |
| 画面像蒙了一层雾 | 检查镜头表面是否有污渍，并按设备清洁说明处理 |
| 白杯不同区域偏黄或偏蓝 | 检查是否有不同颜色的光源同时照射 |

固定手机能减少手抖，但不能自动消除运动主体造成的模糊。特别是光线较暗、曝光时间较长时，要分清“手机在动”和“被拍的人在动”。

### 本节练习

先固定杯子的位置和构图，拍一张自动亮度版本，再拍一张小幅调整亮度的版本。比较杯口、杯身文字和阴影，不用“亮的就是好的”作判断。

然后保持同一杯子，让窗光分别从较正面和较侧面照来，各拍一张。记录哪张更能表现杯身形状，哪张更接近你想要的感觉。本轮的结论只针对这组照片，不把某一种光向当成所有场景的答案。

## 第 3 节 完成一次拍摄并复盘

### 把练习限定成一个小任务

本次任务是“用手机在窗边拍一张能看清杯子、背景简洁、亮部有细节的照片”。准备一个杯子、一处有自然光的桌面和手机即可。

给自己安排约十分钟：整理画面约两分钟，观察光线约两分钟，拍摄约四分钟，选片和记录约两分钟。时间只是练习安排，不是完成作品的速度保证。遇到问题时可以延长。

先完成这一个目标，暂时不加入多个产品、复杂布景或连续动作。减少同时变化的因素，才容易知道某一次调整带来了什么差别。

### 按同一顺序拍摄

1. 说明主体和意图，例如“突出白杯的形状，保留一点窗边环境”。
2. 整理背景，检查杯口、把手、桌沿和画面边缘。
3. 看明暗分布，调整杯子或手机的位置。
4. 选择对焦区域，检查预览亮度，再拍第一张。
5. 放大查看结果，找出一个最明显的问题。
6. 只针对这个问题改一次，拍第二张进行比较。

如果第一张的主要问题是对焦不清楚，就先处理清晰度。不要同时改变构图、加滤镜、换光线，再把结果全部归功于其中一个操作。

### 用检查清单选片

| 检查项 | 可以观察的证据 |
| --- | --- |
| 主体明确 | 缩小照片后仍能很快找到杯子 |
| 关键细节清楚 | 放大时杯身文字或杯口边缘达到本次目标 |
| 背景合适 | 没有明显抢注意力的杂物，保留的环境有作用 |
| 明暗符合意图 | 重要的亮部或暗部仍保留需要的细节 |
| 画面边缘完整 | 没有意外切掉关键部位，也没有无意的倾斜 |

这张表用于检查本次练习。虚化、剪影、倾斜等处理也可以服务于表达；当你主动选择这些效果时，应根据自己的意图判断，而不是机械要求每一处都清晰、每一条线都水平。

### 把问题写成可以重拍的动作

下面是一条假设的记录示例，并不代表已经拍出的实际照片：“杯子旁的红色包装太醒目。下一张先移走包装，保持杯子位置和光线不变。”

有效记录包含三件事：看到了什么问题，准备改变什么，重拍后检查哪里。不要只写“缺乏感觉”。可以写“杯口的亮部看不出边缘，下次降低一点亮度，并比较杯口细节”。

选片时保留一张修改前和一张修改后，避免只凭记忆比较。如果后者并没有改善，也把结果记下来，再选择另一种调整。

### 下一次练习只换一种主体

完成杯子练习后，可以换成一本书或一盆植物，沿用同一套检查顺序。先考虑这次最重要的细节，再决定取景角度；例如书封面的字需要看清，植物的叶片形状值得保留。

练习人像或运动场景时，会增加表情、动作和时机等问题，不必期待拍杯子的方法直接解决所有情况。先把“明确主体、整理背景、观察光线、检查清晰度、针对问题重拍”练熟，再逐步增加难度。

最后为这次练习交付三样东西：一张你选中的照片，一张用于比较的照片，以及一条具体的下一次改进计划。
