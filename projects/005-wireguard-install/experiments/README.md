研究版本为 `hwdsl2/wireguard-install@3f428774e61c95bca60d1e7b80f0c768ca2c6137`。上游安装脚本采用 MIT 许可证；后续引入其源码时须保留上游版权和许可证。WireGuard 的实现具有各自的许可证。

## 环境

建议使用一台可回滚的 Ubuntu 24.04 虚拟机或 VPS，两台独立客户端；记录内核、WireGuard 工具和客户端应用版本。需要管理员权限、可访问的 IPv4 地址或域名，以及可放行的 UDP 端口。云安全组和上游路由器的端口转发由实验环境配置。这个安装脚本会拒绝容器环境。

客户端配置、密钥、二维码与可能含密钥的终端输出不放入研究仓库。截图只展示经过处理的状态、握手时间、计数器和网络路径。
