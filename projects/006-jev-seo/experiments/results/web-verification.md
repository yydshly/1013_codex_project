## 本地 HTTP 与构建

```powershell
python scripts/build_site.py --project 006-jev-seo --output site-preview-jev-seo
python -m http.server 8876 --bind 127.0.0.1 --directory site-preview-jev-seo
```

显式构建仅含 `006-jev-seo`，没有将其他尚未提交项目混入预演。网站、CSS、JavaScript、规则 JSON、提示词、许可证与首页预览图片均实际请求 HTTP 200。构建产物被 Git 忽略。

相对资源路径使用项目目录前缀；章节使用 hash。完整静态预演中的索引可以跳回项目入口。初次本地验证时，项目元信息 `demo_url` 保持空字符串；2026-10-14 后续完成公网发布，验证实际访问后才填写在线入口，详见 [公网发布记录](publication-2026-10-14.md)。
