# RAG 项目中文导读网页

[返回研究说明](../README.md) · [导读页面文件](./index.html) · [复现与验收清单](../experiments/README.md)

本目录已经实现中文导读页，用网页汇总我们对上游项目的理解：能力、价值、适用场景、架构与配置，以及获取资料、整理文档、建立 RAG 和继续扩展的使用路线。

**我们的共同理解：论文是默认应用场景，完整 RAG 的搭建方法和工程架构是我们主要参考的价值。** 新增“共识与一图总览”章节，用三段文字、一张完整图和可展开文字版汇总这层理解。图覆盖定位、能力、价值、原理与架构、使用场景、使用路线、可扩展方向和验收标准。总览图为本仓库直接绘制，提供 2400 × 3500 PNG 与可缩放 SVG 下载；详细来源与编辑方式见 [认知与制作说明](../references/understanding-overview.md)。

**当前是前端导读与规划展示。** 六步流程、场景切换和清单可以交互；没有连接真实论文库、模型或上游后端。农业、技术文档和 GitHub 项目资料是适配方案，上游默认仍为 arXiv AI 论文。上游系统尚未实际复现。

## 内容与交互

| 章节 / 功能 | 说明 |
| --- | --- |
| 项目概览 | 用资料、索引与回答示意解释 RAG 的定位 |
| 共识与一图总览 | 上游做什么、我们参考什么、如何从自己的问题与资料开始；完整总览图、原图打开、PNG / SVG 下载与详细文字版 |
| 能力与价值 | 采集、检索、问答、决策、维护，以及对本仓库研究工作的意义 |
| 六步流程 | 获取资料 → 整理文档 → 解析切块 → 建立知识库 → 检索与回答 → 持续验证；点击查看输入、产物、核对点 |
| 三种场景 | 农业与种植研究、产品与技术资料、GitHub 项目研究；切换资料来源、字段、适配工作与示例问题 |
| 搜索 / RAG 问答示意 | 同一问题的不同输出形式；只解释流程，不生成虚构论文或实际答案 |
| 架构与配置 | PostgreSQL、OpenSearch、Docling、Jina、Ollama 等的分工，默认值与 Agentic 边界 |
| 使用路线 | 先准备主题和资料、跑通最小链路，再扩展为应用基础 |
| 准备清单 | 勾选记录当前浏览器的准备进度；存储不可用时降级为本次会话状态 |
| 下载 Markdown | 导出共同理解、当前选择场景、清单状态、六步流程与验证原则 |
| 研究依据 | 固定 commit 的原仓库、配置、索引、问答与 Agentic 源码链接 |
| 打印入口 | 调用浏览器打印并展开折叠内容；实际打印或 PDF 输出尚未验收 |

清单勾选表示准备进度，不表示实际系统验收通过。页面没有收集密钥、上传资料、发送模型请求或使用追踪服务。

## 本地运行

技术栈：原生 HTML、CSS、JavaScript。没有第三方依赖安装步骤，也无需运行上游 Docker、数据库或模型。

在仓库根目录执行：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory projects/002-production-agentic-rag-course/web
```

打开 <http://127.0.0.1:8766/>。停止时在该终端按 Ctrl+C。8766 为本次预览使用的端口；与项目 001 的本地服务端口分开。

本次应用内浏览器通过 HTTP 完成验证。该浏览器的安全策略不允许 file:// 导航，因此没有在应用内验证本地文件协议；运行上述静态服务即可浏览。

## 文件与部署

| 文件 | 用途 |

| index.html | 八个内容章节、理解总览、结构示意、配置表和研究来源 |

无需安装前端依赖或框架构建。网页发布文件包括 HTML、CSS、JavaScript 和 web/assets/ 内的总览 PNG / SVG。CSS、脚本与图片使用相对路径，导航使用页内锚点，适配独立子路径。仓库汇集器不发布本 README、references/ 中的制作代码或复现材料。

尚未提交的本项目可在仓库根目录进行独立静态发布预演：

```powershell
python scripts/build_site.py --project 002-production-agentic-rag-course --output site-rag-guide-preview
python -m http.server 8766 --bind 127.0.0.1 --directory site-rag-guide-preview
```

随后打开 <http://127.0.0.1:8766/002-production-agentic-rag-course/#understanding>。这个带编号的子路径及图像资源已经本地验证；正式发布按部署约定收集全部已跟踪项目。临时预演产物不提交。

规划访问前缀：/1013_codex_project/002-production-agentic-rag-course/。统一汇集与发布按 [部署约定](../../../docs/deployment.md) 执行。当前未公开部署，project.json 的 demo_url 为空；本地预览不填入 demo_url。
