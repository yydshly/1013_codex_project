## 2. 准备与启动步骤（尚未执行）

先准备 Docker / Compose 与 Python 3.12。以下为 PowerShell 计划，checkout 放在本研究仓库之外；如果目标目录已存在，应检查其版本后复用，不重复克隆或覆盖本地修改。

```powershell
$ragWorkspace = Join-Path $env:LOCALAPPDATA 'codex-reproductions'
New-Item -ItemType Directory -Force -Path $ragWorkspace | Out-Null
Set-Location $ragWorkspace
git clone https://github.com/jamwithai/production-agentic-rag-course.git
Set-Location production-agentic-rag-course
git checkout --detach 424a0eb99edf841994f2a9a053912b489d2a94ff
git rev-parse HEAD
Copy-Item -LiteralPath .env.example -Destination .env
uv sync --frozen --python 3.12
```

启动前按固定源码的 .env.example 与 src/config.py 核对有效配置：

- 混合检索需要 JINA_API_KEY；问题和论文文本将发往对应 API。
- 先关闭可选追踪与机器人（LANGFUSE__ENABLED=false、TELEGRAM__ENABLED=false），跑通最小路径；再分别启用。按固定版本 [src/config.py](https://github.com/jamwithai/production-agentic-rag-course/blob/424a0eb99edf841994f2a9a053912b489d2a94ff/src/config.py) 的双下划线前缀核对有效设置，并在启动后检查实际生效值。
- 主机进程与容器使用不同连接地址：主机用映射端口，容器用 Compose 服务名。不要只修改示例里的一处同义环境变量。
- 固定 Compose 的 Langfuse 主机端口是 3001，容器内部是 3000。禁用应用追踪不等于 Compose 自动跳过监控容器。
- Airflow Dockerfile 使用 2.10.3。先检查构建、入口和 DAG 导入，再决定是否需要修正，不直接照 README 的 3.0 描述升级。
- .env、下载语料、模型、容器卷和日志留在外部复现目录；仅把脱敏结果、实验代码和必要截图整理回本子项目。

配置核对后，计划执行：


## 4. 对比实验设计

建议初轮固定 20 篇论文、30 个问题，覆盖精确术语、同义表达、多论文比较、领域外和语料缺失；这是拟定规模，不是已建立的数据集。每题记录相关论文及原文段落，语料版本固定后再比较。

- 检索对比：BM25、向量、RRF 混合搜索使用相同 top_k，统计相关片段召回和排名。
- 问答对比：普通 RAG 与 Agentic 使用同一模型、相同生成配置，评估原文支持程度、回答完整性、引用正确性与无资料时的处理。
- 重试对比：单独统计首次检索失败的题目，改写后的成功率与新增模型调用，避免只看总体平均值。
- 性能对比：缓存未命中、缓存命中和模型 / 服务预热分组；记录重复次数、并发及 p50 / p95。缓存命中加速不能当作新问题的推理速度。
- 故障对比：记录降级是否改变检索方式、错误类别或依据可靠性，恢复后是否需要人工重启。
- 调参或补丁后，在未参与调参的问题上复核；不要只展示改善的样本。

## 5. 实测结果的记录格式

每轮在 experiments/results/ 新建日期与实验名对应的 Markdown 记录；本次尚未创建实测结果。小型、可公开且已脱敏的输入 / 输出可一并保存，大型语料和原始日志留在外部复现目录。

记录应包含：

1. 日期、固定上游 commit、实验分支和补丁说明。
2. 硬件、运行时、依赖、镜像摘要、实际模型与配置。
3. 数据集、论文版本、问题、标注来源及验收 ID。
4. 请求、实际检索方式与片段、回答、引用和追踪标识。
5. 耗时、缓存状态、重试次数、调用量与故障信息。
6. 通过 / 失败 / 未执行，以及原文、截图或报告证据。
7. 已确认结论与仍未验证的事项，不将模拟结果写成真实模型结果。

完成后回写研究 README 的验证记录。达到核心流程可重复运行的标准后才把 status 改为 reproduced；完成质量分析与研究结论后再考虑 completed，并重新生成、检查根索引。
